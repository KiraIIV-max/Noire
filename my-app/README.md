# NOIRÉ Cafe Website

NOIRÉ is a responsive cafe website built with React, React Router, GSAP, and CSS. It presents the cafe story, categorized menu, gallery, contact details, testimonials, and a validated table reservation form.

## Features

- Responsive homepage with hero, cafe introduction, calls to action, and testimonials
- Menu categories: Coffee, Fast Food, Desserts, Beverages, and Special Dishes
- Menu images, descriptions, and prices
- About, gallery, contact, and reservation pages
- Client-side reservation validation and confirmation message
- Responsive navigation and footer with phone, email, map, and social links
- GSAP scroll reveals and cinematic first-load intro animation
- Reduced-motion support for accessibility

## Run locally

```bash
npm install
npm run dev
```

## Validate

```bash
npm run lint
npm run build
```
